# auoi-fast-voca

이 저장소는 TOEIC 단어를 학습하는 정적 웹앱입니다. 서버 없이 브라우저에서 동작하며, 단어장 데이터를 JSON으로 불러와 화면에 표시하고 학습 진도를 관리합니다.

## 프로젝트 개요

- 저장소 유형: 정적 웹 애플리케이션
- 주요 기술: HTML, CSS, JavaScript
- 실행 방식: 브라우저에서 `index.html`을 열거나 로컬 HTTP 서버를 통해 실행
- 데이터 저장 방식: `data/*.json` 파일
- 상태 유지: `localStorage`를 사용해 선택한 세트, 시작 인덱스, 표시 옵션 등을 저장

## 폴더 및 파일 구조

```text
.
├── CNAME
├── index.html
├── data/
│   ├── README.md
│   ├── toeic_beginner_1500.json
│   ├── toeic_intermediate_1000.json
│   └── toeic_advanced_1000.json
└── README.md
```

### 1) `index.html`

앱의 핵심 파일입니다.

- CSS로 단어장 UI 스타일 정의
- 상단에 문제집 선택 드롭다운, 시작 인덱스 입력, 미리보기/진행 위치 옵션 제공
- 단어 표시 토글(`word`, `mean`, `exp`, `ex`) 기능
- 이전/다음 이동, 스와이프 제스처, 키보드 화살표 네비게이션
- `fetch('./data/<dataset>.json')`로 JSON 파일 로딩
- `localStorage`로 학습 상태 저장

### 2) `data/*.json`

실제 단어 데이터가 들어 있는 폴더입니다.

- `toeic_beginner_1500.json`: 초급 1500개
- `toeic_intermediate_1000.json`: 중급 1000개
- `toeic_advanced_1000.json`: 고급 1000개

데이터 형식은 다음과 같은 배열 구조입니다.

```json
[
  {
    "id": 1,
    "key": "person",
    "phrases": [
      { "phrase": "person", "means": ["사람"] },
      { "phrase": "people", "means": ["사람들"] }
    ]
  }
]
```

각 항목은 다음 의미를 가집니다.

- `key`: 기본 단어 또는 표제어
- `phrases`: 동의어/파생형/변형 단어 목록
- `means`: 해당 단어의 뜻 배열

## 동작 방식

1. 앱이 로드되면 `DATA_FILES` 목록을 읽어 옵션을 생성합니다.
2. 기본 또는 저장된 세트를 선택합니다.
3. `loadDataset()`이 `./data/<file>`을 비동기로 가져옵니다.
4. `setCards()`가 데이터 배열을 정규화하고 화면에 표시할 카드 목록으로 만듭니다.
5. 각 카드에서 단어/뜻/설명/예문을 조건부로 보여줍니다.
6. 사용자가 다음 버튼이나 스와이프를 누르면 학습 인덱스가 이동합니다.
7. 마지막 항목까지 진행하면 `처음부터` 상태로 재시작할 수 있습니다.

## 핵심 기능

- 문제집 선택
- 시작 위치 지정
- 단어/뜻/설명/예문 토글
- 진행률 표시
- 이전/다음 이동
- 스와이프 기반 이동
- 모바일 친화적 레이아웃
- 브라우저 저장 기반 상태 복원

## 실행 방법

브라우저에서 바로 보려면 로컬 HTTP 서버를 권장합니다. 파일 경로만으로는 일부 브라우저 환경에서 fetch 보안 제한 때문에 JSON 로딩이 실패할 수 있습니다.

```bash
cd /path/to/auoi-fast-voca
python -m http.server 8000
```

그 다음 브라우저에서:

```text
http://localhost:8000
```

접속하면 앱을 사용할 수 있습니다.

## 장점

- 의존성이 거의 없음
- 빠르게 실행 가능
- 데이터 파일만 수정하면 단어 목록 확장 가능
- 모바일 UX 기준으로 설계됨

## 한계점

- 백엔드 없음: 사용자 계정/서버 저장 없음
- 정적 JSON 데이터를 기반으로 하므로 동적 관리 기능 제한
- 단어 데이터를 추가하거나 수정하려면 JSON 파일을 직접 편집해야 함

## 요약

이 저장소는 단순한 단어장 앱이지만, 구조가 매우 명확합니다.

- `index.html`: UI와 로직
- `data/*.json`: 단어 데이터
- `localStorage`: 진행 상태 저장

결론적으로, 이 프로젝트는 "정적 HTML 기반 TOEIC 단어 암기 앱"으로 이해하면 가장 정확합니다.
